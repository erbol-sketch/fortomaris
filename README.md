# 💖 Сайт для Томарис

## Как запустить на компьютере
1. Установи Node.js (nodejs.org, версия LTS).
2. Открой папку проекта в терминале и напиши:
   ```
   npm install
   npm run dev
   ```
3. Открой http://localhost:3000

## Telegram (чтобы ответы приходили тебе)
1. В Telegram открой @BotFather → `/newbot` → получишь **токен**.
2. Создай группу, добавь туда своего бота.
3. Напиши в группе любое сообщение.
4. Открой в браузере (подставь свой токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   Найди `"chat":{"id":-100...` — это **chat id** (число с минусом).
5. Скопируй `.env.example` в `.env.local` и вставь токен и chat id.
6. Перезапусти `npm run dev`.

## Выложить в интернет (чтобы Томарис открыла по ссылке)
1. Залей папку на GitHub и зайди на vercel.com → New Project → выбери репозиторий.
2. В Settings → Environment Variables добавь `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
3. Deploy → получишь ссылку. Отправь её Томарис 💌

## Что менять
- Тексты, варианты мест/еды/цветов — файл `config.js`
- Музыка — замени `public/music.mp3` (имя должно остаться таким же)

## Про музыку
Браузеры не разрешают играть звуку без касания пользователя. Поэтому первый экран
с конвертом и кнопкой «Открыть» — после нажатия музыка включается сама и играет весь сайт.
